# RPG-Project

A console-based RPG character creator in Python.

Pick a race, enter your character's appearance, and it rolls your stats (D&D-style, 1-18 on each attribute). Each race gets a different bonus applied automatically.

**Races:**
- **Human** — pick any one stat to add +2
- **Elf** — +2 Dexterity, +2 Charisma, immune to sleep
- **Dwarf** — +2 Strength, +2 Constitution, -2 Charisma, 20% magic resistance

Stats rolled: Strength, Dexterity, Constitution, Intelligence, Wisdom, Charisma

## Run it

```bash
python "Course Project - RPG.py"
```

Requires Python 3. No external dependencies.
